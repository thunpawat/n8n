# workflows/

Importable n8n workflow templates (JSON exports), kept here for version
control. These are **not** part of the n8n platform source — nothing in
this folder is built, linted, or packaged (`pnpm-workspace.yaml` only
globs `packages/*`). Each subfolder is a self-contained workflow with its
own `README.md` covering setup and required credentials.

Import a workflow via the n8n editor: **Workflows → Import from File**.
